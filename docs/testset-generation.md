# Testset Generation

RAGUnit can synthesize evaluation datasets from your documents — no manual labeling required.

---

## Overview

`OllamaTestsetGenerator` takes a corpus of documents and produces a `Testset`:
a list of `TestCase` instances, each with a `Question`, relevant `Context`, and `ReferenceAnswer`.

The generated testset can be exported to CSV or JSON for versioning and reuse across CI runs.

---

## Quick Start

```java
import org.ragunit.core.domain.*;
import org.ragunit.core.testset.*;

List<Document> corpus = List.of(
    new Document("Authentication uses OAuth 2.0 with JWT tokens. Access tokens expire after 3600s."),
    new Document("Rate limits: Free 100 req/min, Pro 1000 req/min, Enterprise unlimited. HTTP 429 on exceed."),
    new Document("All API errors follow RFC 7807 Problem Details: type, title, status, detail, instance.")
);

TestsetGenerator generator = new OllamaTestsetGenerator("qwen2.5:14b");
Testset testset = generator.generate(corpus, 3);

System.out.println("Generated " + testset.size() + " test cases");
for (TestCase tc : testset.cases()) {
    System.out.println("Q: " + tc.question().text());
    System.out.println("A: " + tc.referenceAnswer().text());
    System.out.println();
}
```

---

## Question Types

| Type | Description | Generated by |
|---|---|---|
| `SIMPLE` | Answerable from a single document | Default |
| `MULTI_HOP` | Requires combining two or more documents | Custom distribution |

### Mixed distribution

```java
Map<QuestionType, Double> distribution = Map.of(
    QuestionType.SIMPLE, 0.7,
    QuestionType.MULTI_HOP, 0.3
);

TestsetGenerator generator = new OllamaTestsetGenerator(
    "qwen2.5:14b", distribution);

Testset testset = generator.generate(corpus, 10);
// ~7 simple questions, ~3 multi-hop questions
```

## Export & Import

Generated testsets can be persisted for reproducibility:

=== "CSV"

    ```java
    TestsetExporter exporter = new CsvTestsetExporter();
    exporter.export(testset, Path.of("testsets/v1.csv"));

    // Later...
    TestsetImporter importer = new CsvTestsetImporter();
    Testset loaded = importer.load(Path.of("testsets/v1.csv"));
    ```

=== "JSON"

    ```java
    TestsetExporter exporter = new JsonTestsetExporter();
    exporter.export(testset, Path.of("testsets/v1.json"));

    // Later...
    TestsetImporter importer = new JsonTestsetImporter();
    Testset loaded = importer.load(Path.of("testsets/v1.json"));
    ```

## Using a testset in evaluation

```java
Testset testset = importer.load(Path.of("testsets/v1.json"));
RagJudge judge = new OllamaJudge("qwen2.5:14b");

for (TestCase tc : testset.cases()) {
    Answer answer = myGenerator.generate(tc.question(), tc.context());

    RagAssert.assertThatAnswer(answer)
             .givenContext(tc.context())
             .forQuestion(tc.question())
             .evaluatedBy(judge)
             .isFaithfulToContext(0.80)
             .hasFactualCorrectnessF1(0.75);
}
```

## Custom Ollama endpoint

```java
TestsetGenerator generator = new OllamaTestsetGenerator(
    "qwen2.5:14b",
    "192.168.1.10",  // host
    11434             // port
);
```

---

## Minimum recommended model

`qwen2.5:14b` — question synthesis requires strong instruction-following and JSON output.
Smaller models frequently produce malformed JSON; the generator falls back to a minimal
`TestCase` when parsing fails rather than throwing.
