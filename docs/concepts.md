# Concepts

RAGUnit uses a strict domain model. Every class name comes from the [ubiquitous language](../DOMAIN.md).

## The RAG Pipeline

```
Question ──► [ Retriever ] ──► Context
                                   │
                                   ▼
                            [ Generator ] ──► Answer
```

RAGUnit evaluates two bounded contexts:

| Bounded Context | Question answered | Key metrics |
|---|---|---|
| **Retrieval Evaluation** | Is the Context relevant to the Question? | Relevance, ContextPrecision, ContextRecall |
| **Generation Evaluation** | Is the Answer faithful to the Context? | Faithfulness, AnswerRelevancy, Rejection |

---

## Domain Objects

### Question
The user's input query. Immutable `String`. Must not be blank.

```java
Question q = new Question("What is the boiling point of water?");
```

### Document
A single retrieved chunk of text. Immutable. Forms the `Context`.

```java
Document doc = new Document("Water boils at 100°C at sea level.");
```

### Context
An ordered `List<Document>` retrieved by the Retriever.

### Answer
The text generated by the LLM based on the Context. Immutable.

```java
Answer a = new Answer("Water boils at 100 degrees Celsius.");
```

### ReferenceAnswer
A human-authored ground-truth answer. Required only for `ContextRecall` and `FactualCorrectness`.

```java
ReferenceAnswer ref = new ReferenceAnswer("Water boils at 100°C (212°F) at 1 atm.");
```

## Verdict

A `Verdict` is the output of a `RagJudge` evaluation:

| Field | Type | Description |
|---|---|---|
| `score` | `Score` (double in [0,1]) | The normalized quality value |
| `rationale` | `String` | The judge's explanation |
| `model` | `String` | Model that produced the verdict |
| `statements` | `List<Statement>` | Claim decomposition (Faithfulness) |
| `chunkVerdicts` | `List<ChunkVerdict>` | Per-chunk verdicts (ContextPrecision) |
| `promptUsed` | `Optional<String>` | The exact prompt sent to the judge LLM |
| `rawResponse` | `Optional<String>` | The raw LLM response the verdict was parsed from |

---

## JudgeResult

`JudgeResult` is the structured, inspection-friendly view of one judge evaluation.
When a test fails, a number is not enough — `JudgeResult` carries everything needed
to audit the measurement:

| Field | Type | Description |
|---|---|---|
| `score` | `double` | The normalized quality value |
| `justification` | `String` | Why the judge scored it that way |
| `promptUsed` | `String` | The exact prompt that was sent |
| `rawResponse` | `String` | The raw LLM response |
| `model` | `String` | Model that produced the result |

Retrieve it from any assertion builder after a judged assertion (also populated
when the assertion failed):

```java
AnswerAssert assertion = RagAssert.assertThatAnswer(answer)
        .givenContext(context)
        .forQuestion(question)
        .evaluatedBy(judge);

assertion.isFaithfulToContext(0.80);

JudgeResult result = assertion.lastJudgeResult().orElseThrow();
System.out.println(result.promptUsed());      // audit what was asked
System.out.println(result.justification());   // why this score
```

`AssertionError` messages automatically include the judge's justification
(first 500 characters), so a failing CI run is diagnosable without re-running.

## Judge

A `RagJudge` is an LLM-as-judge. It receives evaluation inputs and returns a `Verdict` (or `FactualCorrectnessVerdict`).

RAGUnit ships `OllamaJudge` out of the box. To use another framework, implement `RagJudge` directly — see [Custom Adapters](integrations/adapters.md).

| Class | Module | Backend |
|---|---|---|
| `OllamaJudge` | `ragunit-core` | Ollama REST API |

## Assertion API

The entry point is `RagAssert`. It returns a fluent builder:

```java
// Retrieval evaluation
RagAssert.assertThatContext(context)
         .forQuestion(question)
         .evaluatedBy(judge)
         .hasRelevanceScore(0.80);

// Generation evaluation
RagAssert.assertThatAnswer(answer)
         .givenContext(context)
         .forQuestion(question)
         .evaluatedBy(judge)
         .isFaithfulToContext(0.80)
         .isRelevantToQuestion(0.75);
```

Each assertion method:

1. Calls the judge (one LLM call per metric)
2. Notifies registered `RagReporter` instances
3. Throws `AssertionError` if the score is below the threshold

## @RagTest

`@RagTest` is a JUnit 5 `@Tag` annotation that marks evaluation tests as expensive:

```java
@RagTest  // equivalent to @Tag("rag-eval")
class MyEvaluationTest { ... }
```

```bash
mvn test                          # fast — @RagTest excluded
mvn test -Dgroups=rag-eval        # run only @RagTest
mvn test -DexcludedGroups=        # run everything
```

---

## Reporter

A `RagReporter` is an observer that silently persists every `AssertionResult` as JSON.

```java
RagJudge judge = new OllamaJudge("qwen2.5:14b");
RagReporter reporter = new JsonFileReporter(Path.of("target/ragunit-report.json"));

RagAssert.assertThatAnswer(answer)
         .forQuestion(question)
         .evaluatedBy(judge)
         .reportingTo(reporter)
         .isFaithfulToContext(0.80);
```

Reporters never throw — a failing reporter never interrupts test execution.
