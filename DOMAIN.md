# DOMAIN.md — RAGUnit Ubiquitous Language

This document is the **source of truth** for naming in RAGUnit.
Rule: every class, interface, record, and public method name MUST use a term from this glossary.
Any deviation requires a comment explaining why.

---

## Bounded Contexts

```
┌─────────────────────────────────────────────────────────────┐
│                      RAG Pipeline                           │
│                                                             │
│   Question ──► [ Retriever ] ──► Context                   │
│                                      │                      │
│                                      ▼                      │
│                               [ Generator ] ──► Answer      │
└─────────────────────────────────────────────────────────────┘
         │                                  │
         ▼                                  ▼
┌─────────────────┐              ┌─────────────────────┐
│  BC: Retrieval  │              │  BC: Generation     │
│  Evaluation     │              │  Evaluation         │
│                 │              │                     │
│  Is Context     │              │  Is Answer faithful │
│  relevant to    │              │  to Context?        │
│  Question?      │              │  Relevant to        │
└─────────────────┘              │  Question?          │
                                 └─────────────────────┘
```

## Glossary

| Term | Definition | Notes |
|------|-----------|-------|
| **Question** | The user's input query submitted to the RAG pipeline | Immutable string value |
| **Context** | The ordered list of documents retrieved by the Retriever | `List<Document>` |
| **Document** | A single retrieved chunk of text, with optional metadata | Immutable record |
| **Answer** | The text generated by the LLM based on the Context | Immutable string value |
| **ReferenceAnswer** | A human-authored ground-truth answer used for recall evaluation | Only metric requiring ground truth |
| **Judge** | An LLM-as-judge responsible for evaluating quality metrics | Core interface: `RagJudge` |
| **Verdict** | The result of a Judge's evaluation: Score + rationale + optional decomposition | Immutable record |
| **Score** | A normalized quality value in [0.0, 1.0] | `double`, never `float` |
| **Statement** | A single claim extracted from an Answer or ReferenceAnswer, tagged supported/unsupported | RAGAS-style decomposition |
| **ChunkVerdict** | Per-chunk relevance judgment produced by ContextPrecision evaluation | Carries rank + relevant flag |
| **ToolCall** | A single tool invocation (name, input, output) in an agentic RAG pipeline | Part of a ToolTrajectory |
| **PromptContext** | Evaluation inputs (question, context, optional answer) passed to a JudgePromptTemplate | Template rendering contract |
| **Faithfulness** | Degree to which the Answer is grounded in the Context (no hallucination) | Generation BC |
| **Relevance** | Degree to which Context or Answer addresses the Question | Both BCs |
| **ContextPrecision** | RAGAS Average Precision: rewards pipelines that rank relevant chunks first | Per-chunk, order-sensitive |
| **ContextRecall** | Coverage of reference-answer claims by the retrieved context | Requires ReferenceAnswer |
| **AnswerRelevancy** | Degree to which the Answer is on-topic for the Question (LLM-only, no embeddings) | Hypothetical-question approach |
| **Rejection** | A correct refusal by the Generator when Context is insufficient | Generation BC |
| **PromptInjection** | An adversarial input attempting to hijack the Generator | Red Teaming BC |
| **PIILeak** | Unintended exposure of Personally Identifiable Information in the Answer | GDPR BC |
| **ToolTrajectory** | The sequence of tool calls made by an agentic RAG system | Agentic BC |
| **Assertion** | A testable claim that a Verdict's Score meets a minimum threshold | Core concept |
| **EmbeddingProvider** | Strategy that computes a dense float vector representation of a text | `ragunit-embedding` module |
| **SemanticSimilarity** | Cosine similarity between two embedding vectors in [-1.0, 1.0] | Embedding-based, vs LLM-based |
| **RagAssert** | The entry point of the fluent assertion API | `RagAssert` class |
| **Reporter** | An observer that silently persists Assertion results as JSON | `RagReporter` interface |
| **RagTest** | A JUnit 5 tag annotation marking expensive evaluation tests | `@RagTest` annotation |
| **MetricType** | Enum identifying each evaluation metric; key for JudgePromptTemplate maps | `MetricType` enum |
| **JudgePromptTemplate** | Functional interface for domain-specific prompt customization per metric | Replaces built-in default prompt |
| **JudgePromptLibrary** | The library of built-in, versioned judge prompts — one public constant per metric (`FAITHFULNESS_V1`…) | Prompt wording never changes in place; a change ships as a new `_Vn` constant |

## Forbidden Names

These names are banned because they are too generic or violate DDD principles:

- `Manager`, `Handler`, `Helper`, `Utils`, `Util`, `Service` (in core)
- `Evaluator` → use `Judge`
- `Result` → use `Verdict`
- `Text` → use `Document` or `Answer` or `Question`
- `Client` → use `OllamaJudge` (the impl carries the infra detail)
