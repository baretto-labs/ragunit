# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability in RAGUnit, please disclose it responsibly by emailing:

**contact@baretto.fr**

Include in your report:
- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested mitigations (optional)

You will receive an acknowledgement within 48 hours and a full response within 7 days.
We will work with you to understand and resolve the issue before any public disclosure.

## Scope

This policy applies to the `ragunit-core` and `ragunit-embedding` modules.
Third-party dependencies (Ollama, JUnit 5, etc.) should be reported to their respective maintainers.
